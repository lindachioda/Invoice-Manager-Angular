# 📄 Invoice Management Dashboard

An Angular web application for managing invoices, customers, and users through a dedicated personal dashboard.
The application uses a mock server to simulate a backend and allows users to register and log in to access their personal area. Once authenticated, users can browse the available invoices, customers, and registered users.
The application also includes an invoice creation form that allows users to enter invoice details and add new invoices to the existing customer records.

The project was developed as an Angular exercise to practice component-based architecture, routing, forms, HTTP requests, data management, and interaction with a mock backend.

### Main Features

* User registration and login
* Personal dashboard
* Invoice management and visualization
* Customer management
* User management
* Create and add new invoices through a form
* Mock backend/server for data management
* Responsive interface
